Bienvenue

Vos cours, annotés sans quitter la page.

Trois gestes suffisent. Tout se fait au clavier ; vos notes restent sur votre appareil, et dans Notion si vous le souhaitez.

  1. 1 Ouvrez un cours Une vidéo, un podcast, un article ou une page Notion.
  2. 2 Ouvrez les notes Écrivez : chaque ligne est horodatée, ou citez le passage lu.
  3. 3 Capturez un schéma L’image arrive dans la note.

Format

Sites vidéo et audio

YouTube, Udemy, Coursera et les vidéos / audios déposés dans Notion sont pris en charge d’office. Sur tout autre site (podcast, radio, plateforme de cours), cliquez sur l’icône Boo Notes ou appuyez sur Alt + Shift + N : Boo Notes s’active pour l’onglet. Dans le panneau, « Toujours activer ici » ajoute le site à cette liste.

    Aucun site ajouté pour l’instant.

    Application Desktop

    Les notes sont toujours enregistrées dans le navigateur. Quand l’application Desktop est lancée, elles lui sont envoyées en local, puis vers votre dossier de notes ou Notion.

    Hors-ligne

    Notion

    Toutes vos notes rejoignent un tableau « Boo Notes — Mes notes » dans la page Notion de votre choix, une page par note, reliées entre elles par vos [[liens]]. Quand l’application Desktop est lancée, c’est elle qui écrit dans Notion ; sinon, l’extension s’en charge.

    Non connecté
    Ouvrir le tableau
    Créez une intégration interne dans Notion, puis copiez son secret.
    Ouvrez la page dans Notion › ••• › Connexions › ajoutez l’intégration, puis copiez son lien.
    Ou lancez l’app Desktop : elle partage sa connexion Notion avec l’extension.
    Tout synchroniser Écrit maintenant dans Notion toutes les notes de ce navigateur.
    Déconnecter Les pages déjà créées restent dans Notion.
