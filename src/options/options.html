Boo Notes

Notes horodatées et captures pour YouTube, Udemy et Coursera.

Bienvenue 👋

Ouvrez une vidéo puis appuyez sur Alt + Shift + N : le panneau de notes s’ouvre et chaque nouvelle ligne reçoit automatiquement l’horodatage de la vidéo.

Raccourcis clavier

Les raccourcis sont globaux au navigateur : ils fonctionnent même quand le focus est dans le lecteur ou dans une autre fenêtre. Chrome limite à quatre les raccourcis proposés par défaut et ignore ceux qui entrent en conflit avec les siens : ceux-là sont gérés directement dans la page (mention « dans la page »).
